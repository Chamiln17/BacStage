## 1. TRANSCRIPT DATA SOURCES & EXTRACTION METHODS

### 1.1 Two Transcript Sources for YouTube Videos

#### **Source 1: Manual Captions (Preferred - High Quality)**

**Characteristics:**
- Created by video creators or professional captioners
- Higher accuracy (Word Error Rate ~1-3%)
- Includes speaker names, proper nouns
- Available for ~60-70% of Algerian educational videos
- **Language:** English subtitles by default; Arabic/French subtitles rare

**Extraction via youtube-transcript-api:**
```python
from youtube_transcript_api import YouTubeTranscriptApi

video_id = 'dQw4w9WgXcQ'
transcript_list = YouTubeTranscriptApi.get_transcript(video_id)

# Returns list of dicts:
# [{'text': 'Hello everyone', 'start': 0.5, 'duration': 2.3}, ...]
```

**Pros:** 100% accurate, no API quota, free
**Cons:** Not available for all videos (~40% missing coverage)

---

#### **Source 2: Auto-Generated Captions (Fallback - Good Coverage)**

**Characteristics:**
- Generated by YouTube's automatic speech recognition (ASR)
- Word Error Rate (WER) ~5-15% (depends on audio quality, accent)
- Available for 95%+ of videos (including non-English videos)
- Metadata: Timestamps, no speaker identification
- **Language:** Supports French, Arabic, English; multilingual videos auto-detected

**Extraction via youtube-transcript-api:**
```python
# Filter for auto-generated transcripts
transcript_list = YouTubeTranscriptApi.get_transcript(
    video_id,
    languages=['en']  # Falls back to auto-generated if manual not available
)

# To explicitly request auto-generated:
transcript_list = YouTubeTranscriptApi.list_transcripts(video_id)
asr_transcript = transcript_list.find_transcript(['en']).fetch()  # ASR version
```

**Pros:** High coverage (~95%+), free, supports multiple languages
**Cons:** Lower accuracy (5-15% WER), hallucinations possible in noisy videos

---

#### **Source 3: OpenAI Whisper (Advanced - Highest Quality)**

**When to Use:** If transcript unavailable from YouTube AND high accuracy critical

**Approach:**
1. Download audio from video (moviepy library)
2. Process with Whisper (local inference, no API costs)
3. 95%+ accuracy on high-quality audio; works with Algerian Arabic/French

**Trade-off:** 5-10 minutes per video (vs. instant for youtube-transcript-api)

**For This Project:** Skip Whisper for MVP (time constraint); use only for <5% of videos without transcripts

### 1.2 Optimal Extraction Strategy for 500 Videos

```python
from youtube_transcript_api import YouTubeTranscriptApi

def get_best_transcript(video_id):
    """
    Try manual caption first; fall back to ASR if unavailable.
    Return None only if both fail (~5% of videos).
    """
    try:
        transcript_list = YouTubeTranscriptApi.list_transcripts(video_id)
        
        # Priority 1: Manually created transcript
        try:
            transcript = transcript_list.find_manually_created_transcript(['en', 'fr', 'ar'])
            return {
                'text': ' '.join([t['text'] for t in transcript.fetch()]),
                'type': 'manual',
                'language': transcript.language,
                'is_generated': False
            }
        except:
            pass
        
        # Priority 2: Auto-generated transcript
        try:
            transcript = transcript_list.find_transcript(['en', 'fr', 'ar'])
            return {
                'text': ' '.join([t['text'] for t in transcript.fetch()]),
                'type': 'auto_generated',
                'language': transcript.language,
                'is_generated': True
            }
        except:
            # Priority 3: Any available transcript (any language)
            transcript = transcript_list.get_transcript(
                transcript_list.get_transcripts()[0].language
            )
            return {
                'text': ' '.join([t['text'] for t in transcript]),
                'type': 'fallback',
                'language': transcript_list.get_transcripts()[0].language,
                'is_generated': transcript_list.get_transcripts()[0].is_generated
            }
            
    except Exception as e:
        print(f"No transcript available for {video_id}: {e}")
        return None

# Expected coverage: ~92-95% of 500 videos (460-475 transcripts)
```

**Coverage Expectations:**
- Videos with manual captions: 60-65% (300-325 videos)
- Videos with auto-generated captions: 30-35% (150-175 videos)
- Videos with NO transcripts: 5% (25 videos) → Skip or use fallback

**Time Cost:** 30-60 minutes for 500 videos (parallel processing)

## 2. TRANSCRIPT FEATURE ENGINEERING

### 2.1 Basic Transcript Metrics (Simple, Always Compute)

#### **Text-Level Features**

```python
import re
from statistics import mean, stdev

def extract_basic_features(transcript_text):
    """Extract simple, fast transcript features."""
    
    features = {}
    
    # 1. LENGTH METRICS
    features['transcript_word_count'] = len(transcript_text.split())
    features['transcript_char_count'] = len(transcript_text)
    features['transcript_sentence_count'] = len(re.split(r'[.!?]+', transcript_text))
    features['avg_words_per_sentence'] = (
        features['transcript_word_count'] / max(features['transcript_sentence_count'], 1)
    )
    
    # 2. VOCABULARY DIVERSITY
    words = transcript_text.lower().split()
    unique_words = len(set(words))
    features['lexical_diversity'] = unique_words / max(len(words), 1)  # Type-Token Ratio
    
    # 3. CONTENT DENSITY (approx reading level)
    # Flesch-Kincaid approximation (more complex = harder to follow)
    words_count = len(words)
    syllables_count = sum(count_syllables(word) for word in words)
    features['syllables_per_word'] = syllables_count / max(words_count, 1)
    
    # 4. TECHNICAL TERMINOLOGY
    technical_terms = ['theorem', 'proof', 'derivation', 'formula', 'equation', 
                       'concept', 'principle', 'hypothesis', 'analysis']
    technical_count = sum(transcript_text.lower().count(term) for term in technical_terms)
    features['technical_term_density'] = technical_count / max(words_count, 1)
    
    # 5. EXPLANATION QUALITY
    explanation_markers = ['because', 'therefore', 'thus', 'since', 'as a result', 
                          'for example', 'specifically', 'in other words']
    explanation_count = sum(transcript_text.lower().count(term) for term in explanation_markers)
    features['explanation_density'] = explanation_count / max(words_count, 1)
    
    return features

def count_syllables(word):
    """Rough syllable count for English."""
    word = word.lower()
    count = 0
    vowels = 'aeiouey'
    previous_was_vowel = False
    for char in word:
        is_vowel = char in vowels
        if is_vowel and not previous_was_vowel:
            count += 1
        previous_was_vowel = is_vowel
    return max(1, count)

# Output (per video):
# {
#   'transcript_word_count': 2150,
#   'transcript_char_count': 12340,
#   'transcript_sentence_count': 45,
#   'avg_words_per_sentence': 47.8,
#   'lexical_diversity': 0.42,
#   'syllables_per_word': 1.35,
#   'technical_term_density': 0.018,
#   'explanation_density': 0.035
# }
```

**Interpretation:**
- **Word count:** Correlates with engagement (15-30 min videos optimal)
- **Sentence length:** Long sentences (>50 words) = harder to follow
- **Lexical diversity:** Higher diversity = more engaging (not repetitive)
- **Syllables/word:** Higher = more complex vocabulary
- **Technical density:** Higher in advanced topics; should match student level
- **Explanation density:** Higher = better pedagogical quality

**Time Cost:** <1 minute per video (5 videos/sec for 500 videos)

```python
    features['gunning_fog_index'] = gunning_fog(transcript_text)
    
    # 4. AUTOMATED READABILITY INDEX
    from textstat import automated_readability_index
    features['automated_readability_index'] = automated_readability_index(transcript_text)
    
    return features
```

#### **Feature Set 3: Topic Extraction & Concept Coverage**

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.decomposition import LatentDirichletAllocation
import nltk
from nltk.tokenize import sent_tokenize

def extract_topic_features(transcript_text, video_subject):
    """
    Extract topics and concepts discussed in transcript.
    Useful for: subject match validation, concept density.
    """
    
    features = {}
    
    # 1. SUBJECT-SPECIFIC KEYWORD FREQUENCY
    # Define domain keywords per Algerian Bac subject
    subject_keywords = {
        'math': ['theorem', 'proof', 'derivative', 'integral', 'function', 
                'equation', 'solution', 'variable', 'limit', 'polynomial'],
        'physics': ['force', 'energy', 'momentum', 'velocity', 'acceleration', 
                   'Newton', 'thermodynamics', 'wave', 'electromagnetic'],
        'science': ['molecule', 'atom', 'reaction', 'compound', 'organism', 
                   'photosynthesis', 'respiration', 'ecosystem', 'evolution'],
        'philosophy': ['concept', 'argument', 'logic', 'ethics', 'knowledge', 
                      'existence', 'reason', 'truth', 'consciousness']
    }
    
    text_lower = transcript_text.lower()
    
    for subject, keywords in subject_keywords.items():
        subject_count = sum(text_lower.count(kw) for kw in keywords)
        features[f'keyword_density_{subject}'] = subject_count / len(transcript_text.split())
    
    # 2. CONCEPT DIVERSITY (# unique key concepts)
    # Simple: count n-grams (2-3 word phrases) that are domain-specific
    sentences = sent_tokenize(transcript_text)
    features['sentence_count'] = len(sentences)
    features['avg_concept_per_sentence'] = len(set(' '.join(sentences[:10]).split())) / max(len(sentences[:10]), 1)
    
    # 3. EXAMPLE-BASED LEARNING (# examples given)
    example_markers = ['example', 'for instance', 'like', 'suppose', 'imagine', 'consider']
    example_count = sum(text_lower.count(marker) for marker in example_markers)
    features['example_frequency'] = example_count / len(sentences)
    
    # 4. QUESTION FREQUENCY (engagement indicator)
    question_count = text_lower.count('?')
    features['question_frequency'] = question_count / len(sentences)
    
    # 5. NEGATION/CONTRAST PATTERNS (pedagogical complexity)
    contrast_markers = ['however', 'but', 'instead', 'otherwise', 'on the other hand', 'although']
    contrast_count = sum(text_lower.count(marker) for marker in contrast_markers)
    features['contrast_frequency'] = contrast_count / len(sentences)
    
    return features

# Output (per video):

#   'keyword_density_physics': 0.002,
#   'sentence_count': 200,

#   'example_frequency': 0.15,             # 1 example per 6-7 sentences
#   'question_frequency': 0.03,            # 1 question per 30 sentences
```

#### **Feature Set 4: Pacing & Speech Patterns (Requires Timestamps)**

```python
def extract_pacing_features(transcript_with_timestamps):
    """
    Extract timing information: How quickly does instructor speak?
    What are pause patterns? (Indicates clarity, emphasis)
    
    Input: List of dicts from youtube-transcript-api with 'start', 'duration' fields
    """
    
    features = {}
    
    # 1. AVERAGE SPEECH RATE (words per minute)
    total_duration_sec = sum(t['duration'] for t in transcript_with_timestamps)
    word_count = sum(len(t['text'].split()) for t in transcript_with_timestamps)
    wpm = (word_count / total_duration_sec) * 60 if total_duration_sec > 0 else 0
    features['avg_words_per_minute'] = wpm
    
    # Interpretation: 150-180 WPM is standard teaching pace
    # <120 WPM = slower, more deliberate (good for complex topics)
    # >200 WPM = fast (may indicate enthusiasm or rushing)
    
    # 2. PAUSE FREQUENCY (long gaps between captions)
    pauses = []
    for i in range(1, len(transcript_with_timestamps)):
        gap = (transcript_with_timestamps[i]['start'] - 
               (transcript_with_timestamps[i-1]['start'] + transcript_with_timestamps[i-1]['duration']))
        if gap > 1.0:  # Pause longer than 1 second
            pauses.append(gap)
    
    features['pause_count'] = len(pauses)
    features['avg_pause_duration'] = sum(pauses) / len(pauses) if pauses else 0
    features['pause_frequency'] = len(pauses) / (total_duration_sec / 60)  # Pauses per minute
    
    # Interpretation: 2-3 pauses/min = good emphasis; >5/min = hesitant
    
    # 3. SEGMENT UNIFORMITY (consistency of pacing)
    segment_durations = [t['duration'] for t in transcript_with_timestamps]
    if len(segment_durations) > 1:
        import statistics
        features['caption_duration_stdev'] = statistics.stdev(segment_durations)
    else:
        features['caption_duration_stdev'] = 0
    
    # Low stdev = uniform pace; high stdev = variable (emphasis/emotion)
    
    return features

# Output:
# {
#   'avg_words_per_minute': 165,    # Moderate pace
#   'pause_count': 45,              # 45 pauses in video
#   'avg_pause_duration': 2.3,      # Average 2.3 second pauses
#   'pause_frequency': 2.1,         # 2.1 pauses per minute (good)
#   'caption_duration_stdev': 1.8   # Moderate variation
# }
```

**Correlation with Engagement:**
- Optimal WPM: 150-170 (not too fast, not too slow)
- Pause frequency 1.5-3/min: Better engagement (shows emphasis)
- Pause frequency >5/min: Hesitation, lost comprehension

### 2.3 Advanced: Topic Modeling (LDA - Optional)

**When to Use:** If you want to automatically identify what topics video covers (unsupervised)

```python
from gensim import corpora, models
from nltk.corpus import stopwords
from nltk.tokenize import word_tokenize
import nltk

nltk.download('stopwords')
nltk.download('punkt')

def extract_lda_topics(transcripts_list, num_topics=5):
    """
    Latent Dirichlet Allocation: Unsupervised topic discovery.
    
    Useful for: Identifying core topics in video without manual labeling.
    Example: Math video on derivatives → Topics might be: 
              [limits, slopes, rules, applications, notation]
    """
    
    # Pre-process all transcripts
    stop_words = set(stopwords.words('english'))
    processed_docs = []
    
    for transcript in transcripts_list:
        tokens = word_tokenize(transcript.lower())
        # Remove short words, stopwords
        tokens = [t for t in tokens if len(t) > 3 and t not in stop_words]
        processed_docs.append(tokens)
    
    # Create dictionary and corpus
    dictionary = corpora.Dictionary(processed_docs)
    corpus = [dictionary.doc2bow(doc) for doc in processed_docs]
    
    # Train LDA model
    lda_model = models.LdaModel(
        corpus=corpus,
        id2word=dictionary,
        num_topics=num_topics,
        random_state=42,
        passes=10  # Number of iterations
    )
    
    # Extract topics for each video
    video_topics = []
    for doc_corpus in corpus:
        topics = lda_model.get_document_topics(doc_corpus)
        # Return top 3 topics by probability
        top_topics = sorted(topics, key=lambda x: x[1], reverse=True)[:3]
        video_topics.append(top_topics)
    
    return lda_model, video_topics

# Output (per video):
# [(topic_id_0, probability_0.45),
#  (topic_id_2, probability_0.28),
#  (topic_id_1, probability_0.15)]
#
# Then manually inspect and label: 
# Topic 0 → "Calculus - Limits"
# Topic 1 → "Applications"
# Topic 2 → "Algebraic Rules"
```

**Pros:** Automatic, no manual labeling needed
**Cons:** Requires interpretation; slow for large corpus
**Time Cost:** 30-60 minutes for 500 videos (one-time training)

**Skip for MVP:** Unless specifically interested in topic classification

**Challenge:** Algerian educational videos often mix French and Algerian Arabic (Darija)

**Key Research Finding [web:115][web:118][web:120]:**
- Algerian YouTube educational content is **heavily code-switched** (Darija + French)

- No pre-trained Darija NLP models readily available

#### **Strategy for Handling Mixed-Language Transcripts**

**Option 1: Language Detection + Segmentation (Recommended)**

```python
from langdetect import detect_langs
from textblob import TextBlob
import re

def split_by_language(transcript_text):
    """
    Identify language segments and handle appropriately.
    Since Darija not widely supported, focus on French/English content.
    """
    
    # 1. OVERALL LANGUAGE DETECTION
    try:
        langs = detect_langs(transcript_text)
        detected = {lang.lang: round(lang.prob, 3) for lang in langs}
    except:
        detected = {}
    
    # 2. SPLIT BY LANGUAGE MARKERS
    # French patterns: "ceci", "où", "ça"
    # English patterns: "the", "this", "that"
    # Darija: Harder without specialized model
    
    fr_pattern = r'\b(ceci|celui|où|ça|c\'est|les|pas|que|pour)\b'
    en_pattern = r'\b(the|this|that|this|there|these)\b'
    ar_pattern = r'[\u0600-\u06FF]'  # Arabic script
    
    fr_matches = len(re.findall(fr_pattern, transcript_text.lower()))
    en_matches = len(re.findall(en_pattern, transcript_text.lower()))
    ar_matches = len(re.findall(ar_pattern, transcript_text))
    
    total_words = len(transcript_text.split())
    
    features = {
        'french_percentage': (fr_matches / total_words) * 100 if total_words > 0 else 0,
        'english_percentage': (en_matches / total_words) * 100 if total_words > 0 else 0,
        'arabic_percentage': (ar_matches / total_words) * 100 if total_words > 0 else 0,
        'detected_languages': detected,
        'primary_language': max(detected.items(), key=lambda x: x[1])[0] if detected else 'unknown'
    }
    
    return features

# Output:
```

```python
def phase4_transcript_extraction(videos_df):

                features.update(extract_basic_features(transcript_text))
                features.update(extract_readability_features(transcript_text))
                features.update(extract_topic_features(transcript_text, row.get('subject')))
                
                # Tier 2 Features (if full transcript with timestamps available)
                if isinstance(transcript_obj, list):  # Has timestamps
                    features.update(extract_pacing_features(transcript_obj))
            
            transcript_features.append(features)
            
            # Progress tracking
            if (idx + 1) % 50 == 0:
                print(f"Processed {idx+1}/{len(videos_df)} videos")
            
            time.sleep(0.1)  # Rate limiting
            
        except Exception as e:
            errors.append({'video_id': video_id, 'error': str(e)})
            print(f"Error on {video_id}: {e}")
    
    # Merge with original dataframe
    transcript_df = pd.DataFrame(transcript_features)
    result_df = videos_df.merge(transcript_df, on='video_id', how='left')
    
    # Report
    print(f"\nTranscript Extraction Summary:")
    print(f"  - Successful: {len(transcript_features)}")
    print(f"  - Failed: {len(errors)}")
    print(f"  - Coverage: {(len(transcript_features) / len(videos_df)) * 100:.1f}%")
    
    return result_df, errors

# Usage:

print("\nFeatures added:")
```

## 6. TROUBLESHOOTING & CONTINGENCIES

### Common Issues

**Issue 1: "No transcripts found for video"**
- **Cause:** Video has no captions (5-10% of videos)
- **Solution:** Skip or mark as `transcript_available=0`; impute missing features with 0 or median
- **Impact:** Minor (don't over-weight these videos in analysis)

**Issue 2: Auto-generated transcripts contain errors (Darija/French code-switching)**
- **Cause:** YouTube's ASR trained primarily on English/clean audio
- **Solution:** Accept as-is; use simpler features (word count, TF-IDF) robust to typos
- **Mitigation:** Mark as `is_generated=1` in features; let model learn to de-weight if needed

**Issue 3: Transcripts truncated or incomplete**
- **Cause:** Video longer than 4 hours (rare); API sometimes returns partial
- **Solution:** Check `transcript_word_count` < 1000 as red flag; re-fetch if possible
- **Impact:** Minimal (<1% of videos)

**Issue 4: Processing slow (>60 sec per video)**
- **Cause:** Inefficient NLP library usage or network latency
- **Solution:** Parallelize using `multiprocessing`; cache API responses
- **Speed:** Should achieve 3-5 videos/min with optimization

### Contingency: Missing Transcripts

If >30% of videos lack transcripts:
1. **Option A:** Use OpenAI Whisper (add 5-10 min per video, better quality)
2. **Option B:** Focus on videos WITH transcripts; stratify analysis
3. **Option C:** Impute missing features using channel-level averages
