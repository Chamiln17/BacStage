## Mathematics (الرياضيات)

### Core Topics (3AS Only)

- **الدوال العددية** (Numerical Functions)
  - الاشتقاقية والاستمرارية (Derivatives and Continuity)
  - النهايات (Limits)
  
- **الدالة الأسية واللوغاريتمية** (Exponential and Logarithmic Functions)
  - الدالة الأسية (Exponential Function)
  - الدالة اللوغاريتمية (Logarithmic Function)

- **التكامل** (Integration)
  - الدوال الأصلية (Primitive Functions)
  - حساب التكامل (Integral Calculus)
  - التزايد المقارن (Comparative Growth)

- **الأعداد المركبة** (Complex Numbers)
  - التحويلات النقطية (Point Transformations)
  - الهندسة باستعمال الأعداد المركبة (Geometry using Complex Numbers)

- **المتتاليات العددية** (Numerical Sequences)

- **الهندسة في الفضاء** (Geometry in Space)
  - حساب المسافات (Distance Calculation)
  - حساب الزوايا (Angle Calculation)

- **الإحصاء والاحتمالات** (Statistics and Probability)
